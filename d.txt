2.using an alpine image create a file name hello.php in its app holder containing the text "this is the paragraph of text stored in file named hello.text".open that file from the app folder and display its contents by running the img as a container 

FROM alpine:latest

RUN mkdir -p /app

RUN echo "this is the paragraph of text stored in file named hello.text" > /app/hello.php

CMD ["cat", "/app/hello.php"]

docker build -t alpine-hello .

docker run --rm alpine-hello

Output:this is the paragraph of text stored in file named hello.textwri

3.Create a container to add two numbers .use two files the first file is addno.py to accept two numbers from the console and calculate the sum.2nd file is  dockerfile which contains the sufficient codes to call addno.py for finding the number .

addno.py
num1 = float(input("Enter first number: "))
num2 = float(input("Enter second number: "))

sum = num1 + num2

print("Sum =", sum)


Dockerfile

FROM python:3.12-alpine

WORKDIR /app

COPY addno.py /app/

CMD ["python", "addno.py"]


docker build -t add-numbers .

docker run -it --rm add-numbers

output:
Enter first number: 30
Enter second number: 20
Sum = 50.0
