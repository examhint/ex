Installation Steps
1.Enable WSL 2 (Windows Subsystem for Linux):Command Prompt / PowerShell.
Open PowerShell or Command Prompt as an Administrator (Right-click → Run as administrator).
Run the following command to install WSL:
 wsl --install 
      3. Verification: Restart your computer when prompted. Once rebooted, open PowerShell and  verify WSL 2 is installed by typing wsl --status. 
2. Download Docker Desktop Installer:Official Browser Download.
Go to the official Docker website: [https://www.docker.com/products/docker-desktop/](https://www.docker.com/products/docker-desktop/).
Click Download for Windows to download the Docker Desktop Installer.exe file.
3. Run the Installer:Setup Wizard.
Locate and double-click Docker Desktop Installer.exe.
On the Configuration screen:
Check the box for Use WSL 2 instead of Hyper-V (recommended).
(Optional) Check the box to add a shortcut to your desktop.


Click Ok and wait for the installation files to uncompress and install.
Click Close and restart to complete the setup process.
4. Launch & Complete Initial Setup:Docker Desktop Application.
After restarting Windows, launch Docker Desktop from the Start Menu or desktop shortcut.
Accept the Docker Subscription Service Agreement when prompted.
Choose your installation mode (Per-user or All-users) and sign in (or select Continue without signing in).
Verification: Wait until the status icon in the bottom-left corner of Docker Desktop turns solid Green (indicating Docker Engine is running).
5. Verify Docker CLI via Terminal:PowerShell / Command Prompt.
Open PowerShell or Command Prompt.
Test the Docker Installation and version:
 docker --version

Kubectl Basic Commands:

# Verify kubectl version (client and server) 
  kubectl version --client 

# Check cluster connection details
  kubectl cluster-info 

# View cluster nodes and their status (Ready/NotReady)
  kubectl get nodes

 # View overall resource usage of nodes
  kubectl top nodes 

Pods Management Commands:

# Create and start a basic Nginx pod
 kubectl run nginx-pod --image=nginx:latest 

# List all pods in the default namespace 
kubectl get pods 

# Delete a pod by name 
kubectl delete pod test-pod
